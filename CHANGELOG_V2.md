# CHANGELOG V2

## Why V2 exists

V1 pilot/audit successfully completed all E0–E7 runs but exposed two numerical defects before manuscript interpretation:

1. Gaussian continuity-corrected point masses used direct CDF subtraction in the far right tail. When both CDF values were nearly one, catastrophic cancellation produced severely inflated Gaussian probabilities.
2. The V1 local-mode defensive importance sampler could under-cover singular/nested M2 regions when data were generated by or close to M1. Rare dominant importance weights could reverse the sign of the estimated Bayes factor.

V2 is a numerical-method correction and preregistered experiment extension. It is not a result-driven seed search.

## Code changes

### `src/brw/likelihoods.py`

- Added stable normal interval-mass evaluation.
- Right tail now uses `Phi(hi)-Phi(lo)=Phi(-lo)-Phi(-hi)` in log space.
- Added tests for far-right-tail stability and symmetry.

### `src/brw/importance.py`

- Retained V1 local-mode IS as an explicit E4 baseline.
- Added ridge-aware IS with prior, equal-regime, `pi≈1`, `pi≈0`, and label-switched local Gaussian components.
- Proposal density evaluates the complete mixture, not only the component that generated a sample.
- Added reusable log-weight diagnostics.

### `src/brw/evaluation.py`

- Production M2 evidence now uses adaptive ridge-aware IS.
- Added preregistered escalation rules and repeatability checks.
- Added `evidence_numerical_status`, final budget, repeat SD, total samples, ESS and max-weight diagnostics.
- Gaussian M1 evidence now uses adaptive quadrature.

### Experiments

- E1: corrected evidence-method metadata and switched to adaptive V2 estimator.
- E2: added fixed-delta and fixed-kappa designs; stores M1/M2 evidence errors separately.
- E3: added hard/medium/easy M2 separations and paired datasets across priors.
- E4: expanded numerical stress set; compares MC, Sobol, V1 local IS, V2 ridge IS; reference now independent Sobol QMC with escalation and explicit gate.
- E5: Bayesian branch switched to V2 estimator.
- E6: added regime-separation dimension.
- E7: densified q grid, added q<.5 controls and finite-T theoretical VIF.

### Reproducibility

- Added `smoke_v2` and `paper_v2` profiles; legacy `smoke` and `paper` profiles are preserved.
- `run_all.py` writes a resolved `config_snapshot.json`.
- `environment.json` records Git commit when available.
- Audit reports numerical status and E4 gate outcome.
- Result bundle includes V2 protocol, changelog and exact profile configuration.

## What V2 intentionally does not change

- The main scientific question.
- V1 data-generation seed base.
- E0 simulator-validation design.
- The central E1 N/T/delta-p grid.
- The rule that raw rows are never manually removed because they look unfavorable.
